# EduNova

EduNova es una aplicación web diseñada para la gestión integral y el registro de beneficiarios en entidades sin fines de lucro (casas hogar, guarderías y dispensarios comunitarios).

##  Funcionalidades Planeadas
- **Registro de Beneficiarios:** Gestión y control de expedientes de usuarios de la institución.
- **Operaciones CRUD:** Creación, lectura, actualización y eliminación de registros principales.
- **Autenticación y Roles:** Control de acceso por perfiles de usuario (Administrador, Personal, Docente).


## Tecnologías
- **Lenguaje:** Java / PHP
- **Framework / Servidor:** Spring Boot / Apache (XAMPP)
- **Control de Versiones:** Git, GitHub, GitHub Desktop
